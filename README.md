# 사서를 잡아라!

도서관 방탈출 마지막 단계용 **독립 실행형 웹 게임**입니다. 다른 방탈출 저장소와 연결되지 않습니다.

고양이 달리기 30초 → 원본 SD 엔딩 만화 5장 → 실제 종이 엽서 접기 → 정답 입력 → 최종 완료 순서입니다. 체력 3칸, 2단 점프, PC Space 입력과 모바일 터치를 지원합니다. 탭을 떠나면 게임이 일시 정지됩니다.

## 실행

Node.js가 설치된 환경에서:

```sh
npm start
```

http://127.0.0.1:4173 에 접속합니다. 정적 웹 서버에서는 이 저장소 최상위 `index.html`을 실행하면 됩니다. `.nojekyll`과 상대 경로를 포함해 GitHub Pages의 저장소 하위 경로를 지원합니다. GitHub 소스 업로드와 웹 페이지 공개 설정은 별개입니다.

## 오프라인 파일 만들기

```sh
npm run build:offline
```

생성된 `사서를잡아라_바로실행.html`은 모든 이미지와 코드를 포함합니다. 다운로드 후 브라우저에서 더블클릭해 플레이할 수 있습니다. 생성 파일은 Git에 중복 업로드하지 않습니다.

## 수정 위치

- `config.js`: 시간, 체력, 중력, 1·2단 점프, 속도, 장애물 간격, 캐릭터 크기, 만화 자동 진행 시간
- `engine.js`: 물리, 충돌, 관대한 몸통 판정, 정답 정규화
- `renderer.js`: 분리된 도서관 배경과 바닥, 장애물, 원본 투명 스프라이트 정렬
- `app.js`: 입력, 로딩, 화면 상태, 만화, 한글 입력 조합 보호, 완료 처리
- `index.html` / `styles.css`: 한국어 UI와 반응형 화면
- `assets/`: v2 달리기·피격 고양이와 사서 스프라이트, 실측 프레임 좌표, 엔딩 5장, 접기 도식

원본 시안 이미지와 실제 엽서 참고 원본은 배포에 포함하지 않습니다. 정답 전에 완성 장면이나 정답 문장을 화면에 보여주지 않습니다.

## 완료 처리

완료 시 현재 창에 `escape-room:complete` CustomEvent가 한 번 발생하고 localStorage에 완료 기록을 저장합니다. 현재 버전은 독립 게임으로 동작합니다. 나중에 iframe 연동이 필요하면 config.js의 parentOrigin에 정확한 부모 origin을 설정할 수 있습니다. 기본값 null은 외부 메시지를 보내지 않습니다.

## 크기·충돌 반응 v2

고양이 기준 높이는 58px, 사서는 180px입니다(960×500 논리 좌표). `sprite-layout-v2.json`의 실측 source_rect·anchor_local과 cat=261/librarian=391 기준 높이를 사용합니다. 달리기와 피격 고양이는 같은 배율을 공유합니다. 실행 스프라이트는 무손실 WebP이며 알파와 보이는 픽셀을 유지합니다.

`collision.js`는 회전한 책의 OBB와 몸통·머리 상자의 SAT, 이동 경로의 TOI를 계산합니다. 엔진은 접촉면에서 위치를 되돌리고 작은 간격을 확보한 뒤 양쪽에 화면 기준 반동을 적용합니다. 무적이나 피해 이력은 분리 검사를 생략하지 않습니다. 70ms hit-stop은 게임 시간·월드·반응 시간을 함께 멈추고, 착지에 맞춰 피격 시트가 복귀합니다. 마지막 체력도 반응을 보여 준 뒤 실패합니다.

F2는 개발용 충돌/접촉점/속도 표시를 켜고 끕니다. 기본 게임 화면에서는 꺼져 있습니다. `/tests/collision-preview.html`은 실제 엔진·렌더러로 바닥/공중/위·아래 접촉/마지막 체력을 한 프레임씩 확인하는 개발 화면입니다.

자동 검증은 71개입니다. 실제 브라우저 확인 기록은 `VALIDATION_V2.md`에 정리합니다. 오프라인 HTML은 `npm run build:offline`으로 다시 생성할 수 있습니다.


## 평면 배경·소품과 WebP 경량화

실측 source_rect로 자른 도서관 벽(0~415)과 바닥(415~500)을 각자 균일 배율로 반복합니다. 전역 타일 번호를 기준으로 번갈아 좌우 반전하며 벽은 거리 0.22배, 바닥은 1배로 이동합니다.

닫힌 책·펼친 책·팔락이는 책·상자·책더미·바구니의 6종을 동일 비율로 렌더링합니다. props.js는 ground_anchor_local/pivot_local과 실제 외곽을 충돌과 함께 변환합니다. 펼친 페이지의 큰 빈 공간은 오목 외곽을 볼록 분할해 제외합니다. 책 모양은 높이/세 발사 곡선 선택과 독립적입니다.

이미지는 기존 실행 PNG 16,644,702바이트에서 새 배경·소품을 포함한 WebP 3,917,168바이트로 약 76.5% 감소했습니다(이미지 합계, HTTP 헤더/코드 제외). 새 그림까지 모두 PNG로 배포할 경우와 비교하면 약 80% 작습니다. 초기 로드는 러너 이미지 5개 2,553,816바이트이며 만화 5장은 시작 버튼을 누른 뒤 미리 불러옵니다.

스프라이트/소품은 무손실 WebP(원본 해상도·알파·보이는 RGB 동일), 배경은 quality 90, 엔딩은 quality 88입니다. 엔딩 컷 순서와 내용·글자는 유지합니다. 원본 PNG는 배포에서 제외했으며 Git 이력과 작업 백업에 보존됩니다. 기존 Git 이력 자체를 줄이기 위한 강제 재작성은 하지 않았습니다.

- assets/props/props-layout.json, assets/background/background-layout.json: 실측 좌표와 반복 설정
- scripts/build-scene-data.mjs: JSON에서 브라우저용 scene-data.js 생성 (`npm run build:scene`)
- props.js: 비율·접지·회전·볼록 분할 공통 처리
- tests/scene.test.mjs: 실제 6종 외곽, 빠른 충돌, 빈 공간, 반복 경계, 용량 검사
- tests/collision-preview.html: 실제 엔진/렌더러의 소품 6종·배경 반복·충돌 확인 UI

오프라인 HTML도 같은 WebP로 생성합니다. 생성물은 배포 저장소에 중복 커밋하지 않습니다. 상세 크기/변환 해시는 asset-verification.json에 있습니다.

튕겨 나온 이전 소품이 정상 정리되기 전에 다음 소품과 겹치지 않도록 도착 예상 시간과 남은 정리 시간을 비교해 생성을 짧게 유예한다. 기존 속도·최소 간격·반동 값은 유지하며 30초 동안 소품끼리의 침투도 0.002px 미만으로 검증한다.

## 게임 중심 화면·추격 속도·진짜 포물선 (chase3)

게임 밖의 큰 소개/브랜드/푸터 대신 제목·30초/체력·게임·점프만 위쪽에 표시합니다. 노트북 화면 높이에 맞춰 프레임과 만화의 최대 높이도 제한합니다. 만화/엽서/완료 전환 때 화면 위로 이동합니다.

이동은 410→494px/s, 두 캐릭터의 시트 재생은 24fps로 모두 이전의 2배입니다. 피격 소품은 날아가며 .2~.9초에 페이드한 뒤 삭제합니다. 책은 중력550과 초기 수직 속도를 계속 적분합니다. 낮은 던지기140/160/180, 높은 던지기330/350/370의 세 곡선을 형태와 독립적으로 고릅니다. 바닥 접촉 시 실제 회전 외곽으로 위치를 보정하고 속도 반발계수 sqrt(.5)를 써 반등 높이를 약 절반으로 만듭니다.

30초 성공 시 배경 이동을 고정하고 두 캐릭터가 멈춰 앞의 츄르를 발견하는 2.2초 연출 뒤 기존 만화 5컷으로 이어집니다. 0체력 상태로 30초를 넘기면 마지막 피격 반응 뒤 실패하며 성공 연출로 바뀌지 않습니다. `tests/collision-preview.html`의 책 던지기/30초 종료 연출 버튼으로 실제 엔진·렌더러를 확인할 수 있습니다.

최신 검증: `VALIDATION_CHASE3.md` (자동 52개, 브라우저 결과와 구분).


## 사서 모션 업데이트 (motion4)

현재 사서는 세 클립 모두 골반 (144,212)과 180/270 단일 배율을 사용합니다. 각 프레임의 duration_ms로 달리기 668ms, 투척 500ms, 넘어짐 1060ms를 재생합니다. 고양이는 기존 58/261 배율과 24fps를 유지합니다. 이전 문단의 사서 24fps/391px 기준과 discovery 2.2초 설명은 chase3 이력이며 현재 버전에는 이 단락이 적용됩니다.

달리는 하체 위에 허리 위 투척만 합성합니다. 책의 모양·경로·곡선·ID를 준비 시 고정하고 실제 크기의 책을 손 접촉점에 붙입니다. 230ms 경계를 통과할 때 그 책을 한 번 생성하고 달리기 시계를 이어갑니다. 대기 투척은 하나까지만 보관합니다.

낮은 책 더미와 별개로 약 105×136px의 높은 두 층 책 더미가 8초 이후 최대 두 번 등장합니다. 실제 알파 외곽을 볼록 분할해 충돌을 검사하고 두 층이 하나의 피해 이력을 공유합니다. 위험 소품은 캐시한 1.7px 밝은 알파 윤곽과 작은 그림자를 표시하며 높은 더미에만 작은 ↑↑를 표시합니다.

30초가 되면 시간·배경 이동·입력·피해·새 투척을 멈춥니다. 첫 640ms는 지정 발끝을 고정하고 이후 400ms 동안 같은 골반 좌표에서 오른쪽 화면 밖으로 날아갑니다. 추가 90도 회전은 없습니다. 1060ms 뒤 약 100ms 간격을 두고 기존 만화로 이어집니다. 일시정지·탭 숨김은 종료 시계도 멈추고 체력 0은 실패가 우선합니다.

현재 실행 WebP 13개는 합계 3,637,414바이트로 이전보다 약 7.1% 작습니다. 초기 장면은 8개 2,274,062바이트입니다. 새 사서 3시트와 높은 더미는 제공 PNG와 픽셀이 같은 무손실 WebP입니다. 큰 PNG·참고 이미지·개별 프레임과 이전 사서 시트는 실행 자산에서 제외했습니다.

`librarian-motion.js`는 시간·골반·발·손·비행 좌표를 다룹니다. `npm run test:stack-sweep`는 실제 엔진과 SAT 연속 충돌로 410~494px/s의 7개 속도에서 단일/이단 점프 타이밍을 탐색하고 `tests/double-stack-results.json`을 다시 만듭니다. 결과에는 소스 해시와 시간 샘플 오차를 뺀 최소 여유가 있습니다. 기본 테스트에서 단일 점프 전 범위와 이단 점프 대표 입력을 다시 검사합니다.

F2는 골반·머리·지지 발·바닥 진단도 표시합니다. 개발 확인 화면은 투척 준비·230ms 해제·소품 7종·발 고정·비행을 0.01초 단위로 확인할 수 있습니다. 현재 상세 검증은 `VALIDATION_MOTION4.md`에 기록합니다.


## 정답 직후 돌아온 장면과 감사 대사 (after5)

엽서의 기존 정답을 확인한 같은 동작에서 키보드를 닫고 철푸덕 앉은 사서와 돌아온 고양이를 표시합니다. 사서의 손 확인 → 감사 → 고양이의 냐옹 → 약속 → 모험 마치기 순서로 버튼을 눌러 진행합니다. 최종 완료 알림은 마지막 대사 뒤에 한 번 발생합니다.

`after-ending/`에 승인된 대사와 화면 컴포넌트가 있으며 실행 그림은 `returned-scene.webp` 한 장(69,496바이트)입니다. 큰 PNG·분리 배경·참고 충돌 그림은 배포에 추가하지 않았습니다. 그림은 정답 이후에만 읽으므로 시작 이미지 요청8개/2,274,062바이트는 같습니다.

후반 저장 키는 기존 completionKey에 `:after-answer:v1`을 붙입니다. 정답 직후·감사 중·최종 완료에서 새로고침하면 같은 단계로 복원하며 완료 알림을 재발송하지 않습니다. 예전 완료 기록도 인정합니다. 이야기 처음부터는 해당 게임의 저장 두 개만 삭제하고 다른 게임 기록을 보존합니다. 저장을 차단한 브라우저에서도 현재 세션을 진행할 수 있습니다.

`npm test`89개가 통과하며 전체 게임 흐름, 승인된 대사, 연타/키보드, 완료1회, 저장 복원·호환·삭제 범위, 저장 차단과 오프라인 내장 그림을 확인합니다. `npm run check`는15개 자산 해시·경로를 검사합니다. 기존 게임 물리·스프라이트·원본 만화5장과 배경 파일은 수정하지 않았습니다.

`tests/after-ending-preview.html`은 실제320/360/390/760px iframe에서 후반 화면을 확인하는 개발 도구입니다. 기본 게임의 정답 판정이나 완료 기록을 변경하지 않습니다. 상세 검증은 `VALIDATION_AFTER5.md`에 기록합니다.


## 발견 장면·책 더미·연속 투척 조정 (balance6)

30초 도착 시 츄르를 발견하는 자세와 문구를3초간 보여 준 뒤 기존 발 걸림/비행/짧은 대기를 진행합니다. 발견부터 만화까지4.16초이며 전체 구간에서 시간과 배경 이동을 고정합니다. 일시정지와 탭 숨김도 같은 시계를 멈춥니다.

두 층 책 더미의 보이는 크기를 약105×136px에서78×124px로 줄였습니다. 높이는약9%,폭은약26% 줄였으며 이 소품에 한해 가로/세로 배율을 따로 적용합니다. 그림·피벗·실제 알파 외곽·회전·접지·윤곽 캐시가 같은 두 배율을 사용합니다. 원본 이미지를 다시 압축하거나 기존 다른6종의 비율을 바꾸지 않았습니다.
