# 사서를 잡아라!

도서관 방탈출 마지막 단계용 **독립 실행형 웹 게임**입니다. 다른 방탈출 저장소와 연결되지 않습니다.

고양이 달리기 30초 → 원본 SD 엔딩 만화 5장 → 실제 종이 엽서 접기 → 정답 입력 → 최종 완료 순서입니다. 체력 3칸, 2단 점프, PC Space 입력과 모바일 터치를 지원합니다. 탭을 떠나면 게임이 일시 정지됩니다.

## 실행

Node.js가 설치된 환경에서:

```sh
npm start
```

http://127.0.0.1:4173 에 접속합니다. 정적 웹 서버에서는 이 저장소 최상위 `index.html`을 실행하면 됩니다. `.nojekyll`과 상대 경로를 포함해 GitHub Pages의 저장소 하위 경로를 지원합니다. GitHub 소스 업로드와 웹 페이지 공개 설정은 별개입니다.

## 오프라인 파일 만들기

```sh
npm run build:offline
```

생성된 `사서를잡아라_바로실행.html`은 모든 이미지와 코드를 포함합니다. 다운로드 후 브라우저에서 더블클릭해 플레이할 수 있습니다. 생성 파일은 Git에 중복 업로드하지 않습니다.

## 수정 위치

- `config.js`: 시간, 체력, 중력, 1·2단 점프, 속도, 장애물 간격, 캐릭터 크기, 만화 자동 진행 시간
- `engine.js`: 물리, 충돌, 관대한 몸통 판정, 정답 정규화
- `renderer.js`: 분리된 도서관 배경과 바닥, 장애물, 원본 투명 스프라이트 정렬
- `app.js`: 입력, 로딩, 화면 상태, 만화, 한글 입력 조합 보호, 완료 처리
- `index.html` / `styles.css`: 한국어 UI와 반응형 화면
- `assets/`: v2 달리기·피격 고양이와 사서 스프라이트, 실측 프레임 좌표, 엔딩 5장, 접기 도식

원본 시안 이미지와 실제 엽서 참고 원본은 배포에 포함하지 않습니다. 정답 전에 완성 장면이나 정답 문장을 화면에 보여주지 않습니다.

## 완료 처리

완료 시 현재 창에 `escape-room:complete` CustomEvent가 한 번 발생하고 localStorage에 완료 기록을 저장합니다. 현재 버전은 독립 게임으로 동작합니다. 나중에 iframe 연동이 필요하면 config.js의 parentOrigin에 정확한 부모 origin을 설정할 수 있습니다. 기본값 null은 외부 메시지를 보내지 않습니다.

## 검증

```sh
npm test
npm run check
```

테스트 26개는 점프·착지·피격·무적·재도전·30초 완주·만화·오답·정답 변형·한글 조합·완료 기록과 오프라인 HTML 생성을 확인합니다. 화면 상태 테스트는 Node VM의 DOM/Canvas 대역이며 실제 브라우저 렌더링 검증과 구분됩니다. 자산 검사에서 원본 SHA-256·이미지 크기·알파·경로를 검증합니다.

실제 모바일·PC 화면 배치와 실기기 터치/IME는 아직 미확인입니다. 검증 환경의 로컬 브라우저 연결이 시간 초과되어 실제 화면 검증을 완료하지 못했습니다.

## 크기·충돌 반응 v2

고양이 기준 높이는 58px, 사서는 180px입니다(960×500 논리 좌표). `sprite-layout-v2.json`의 실측 source_rect·anchor_local과 cat=261/librarian=391 기준 높이를 사용합니다. 달리기와 피격 고양이는 같은 배율을 공유합니다. 원본 PNG의 알파와 픽셀은 유지합니다.

`collision.js`는 회전한 책의 OBB와 몸통·머리 상자의 SAT, 이동 경로의 TOI를 계산합니다. 엔진은 접촉면에서 위치를 되돌리고 작은 간격을 확보한 뒤 양쪽에 화면 기준 반동을 적용합니다. 무적이나 피해 이력은 분리 검사를 생략하지 않습니다. 70ms hit-stop은 게임 시간·월드·반응 시간을 함께 멈추고, 착지에 맞춰 피격 시트가 복귀합니다. 마지막 체력도 반응을 보여 준 뒤 실패합니다.

F2는 개발용 충돌/접촉점/속도 표시를 켜고 끕니다. 기본 게임 화면에서는 꺼져 있습니다. `/tests/collision-preview.html`은 실제 엔진·렌더러로 바닥/공중/위·아래 접촉/마지막 체력을 한 프레임씩 확인하는 개발 화면입니다.

자동 검증은 26개입니다. 실제 브라우저 확인 기록은 `VALIDATION_V2.md`에 정리합니다. 오프라인 HTML은 `npm run build:offline`으로 다시 생성할 수 있습니다.
